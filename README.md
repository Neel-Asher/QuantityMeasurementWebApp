# QuantityMeasurementWebApp

## UC14: Render History List

+ Implements rendering of history records in the UI.
+ Adds renderHistory(records) function in ui.js.
+ Dynamically builds list items from history data.
+ Clears previous entries before rendering new ones.
+ Displays placeholder message when no records exist.
+ Formats each entry with expression, result, and timestamp.
+ Uses toLocaleString() for readable date-time display.
+ Integrates with loadHistory() in script.js.
+ Ensures safe handling of undefined or empty data.
+ Enhances user visibility of past calculations.
