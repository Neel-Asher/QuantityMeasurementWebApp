# QuantityMeasurementWebApp

## UC0: QuantityMeasurementWebApp

+ A simple Quantity Measurement Web Application UI built using HTML and CSS.
+ The application allows users to select different measurement types such as Length, Weight, Temperature, and Volume.
+ Users can choose actions like Comparison, Conversion, or Arithmetic operations on selected quantities.
+ The interface provides FROM and TO input fields for entering and viewing measurement values.
+ Users can select different units from dropdown menus for accurate measurement operations.
+ The layout is designed using flexbox for responsive and clean alignment of components.
+ Icons are used to visually represent each measurement type for better usability.
+ The styling is implemented using a separate CSS file for modular design.
+ JavaScript functionality can be added later to implement actual conversion and comparison logic.
+ This project demonstrates basic front-end development practices including structured HTML and organized CSS styling.
