# QuantityMeasurementWebApp

## UC15: Handle Type Card Click

+ Handles user interaction when selecting a measurement type.
+ Updates application state using data-type attribute.
+ Highlights selected type card using active class.
+ Clears input values on type change.
+ Resets result display to default.
+ Fetches units dynamically based on selected type.
+ Repopulates FROM and TO dropdowns with new units.
+ Resets selected unit state values.
+ Handles API errors gracefully without breaking UI.
+ Ensures consistent and reactive user experience.
